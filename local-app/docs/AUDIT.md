# 0.2.0 桌面应用检查记录

检查范围：Tauri 宿主、标签页与保存、资料库/文件夹、CLI/本地 IPC、技能安装、构建发布，以及 Yarn 依赖。此记录描述已检查的路径，不代表软件不存在其他缺陷。

## 发现与修复

- 本地工程的 113 条 TypeScript 报错主要由两套 React 类型和缺失的全局声明连锁产生；统一版本并补齐编译上下文。
- 最后一个标签页关闭后保留空工作区；侧栏只高亮当前激活的图；新建只由用户操作触发。
- 切换、关闭和退出前等待保存；捕获编辑时的快照，串行写入；失败时保留画布并显示错误，支持重试。
- 重新打开图时读取最新内容；资料库自动保存不覆盖名称/收藏，不复活已删除数据，并检测外部程序对元素、状态、附件的并发修改。
- 无效文件返回明确错误；磁盘图稿使用同目录临时文件与原子替换，避免写到一半破坏原文件。
- CLI 的同名写操作拒绝模糊匹配；参数和图稿格式校验；`render` 默认只导出，`--save` 才按名称写入库。
- IPC 仅监听本机回环，写请求要求每次启动生成的令牌，令牌文件仅当前用户可读；拒绝浏览器 Origin；限制请求大小、并发数、缩放范围；渲染错误返回失败而非空图片。
- PNG 使用安全临时文件；CLI 显式输出后清理临时产物；渲染自动启动 App 并等待监听器就绪。
- 设置页提供技能简介、客户端检测、安装状态和终端选择；内置经过 SHA-256 校验的 Node，安装过程无需联网、sudo、npm 或 Python。更新已有同名技能前备份，保留原有 `excalidraw` 技能。
- 发布采用固定版本、固定 Developer ID 身份、Apple Silicon/Intel 独立 DMG、公证、校验和与来源提交信息；禁止覆盖旧产物。取消提交后自动打包、强制退出并替换运行中 App 的旧钩子。

## 依赖告警说明

生产依赖审计原有 213 条路径级告警，修复后剩 2 条，均为本地工作区 `@excalidraw/excalidraw@0.18.0` 的同一告警 GHSA-39h7-pwv7-rc3x。该公告明确其修复为升级 `@excalidraw/mermaid-to-excalidraw` 至 2.2.2；本仓库已使用该版本，并升级 Mermaid、DOMPurify、Nano ID 等实际依赖。保留上游工作区版本号，不通过伪造版本号隐藏审计信息。

全仓（含开发与打包工具）最终 Yarn 审计同样只剩上述 2 条重复告警，实际依赖的低/高/严重告警均为 0。更新 Vite 6.4.3、Vitest 4.1.11、Sass 及其他构建依赖；测试迁移改为明确检查图形真实 ID 的唯一性与撤销状态，避免依赖不参与序列化的测试专用 Symbol。Yarn 的历史 peer dependency 提示与安全告警、TypeScript 错误是不同概念。

## 发布限制

本机检查 `security find-identity -v -p codesigning` 返回 0 个可用身份。因此当前只能验证未公证预览构建；正式签名、公证及双架构 CI 需要按 [RELEASING.md](RELEASING.md) 配置 Developer ID 证书和 Apple 凭据后执行。未用自签名证书冒充苹果公证。

资料库不上传 GitHub。仓库维持私有，下载 Release 需要仓库读权限。

## 验收结果

- 全仓：120 个测试文件通过，1753 项通过，47 项原有跳过，1 项待办；未接受失败测试生成的快照变化。
- 桌面：12 项标签页、自动保存、输入校验测试；CLI：5 项资料库/参数/模板布局测试；Rust：5 项原子保存、安装备份、终端配置、IPC 授权及失败回传测试。
- 根目录及桌面 TypeScript 检查通过；桌面源码 ESLint 无错误和警告。
- macOS 原生界面：新建、快速切换后恢复图形、唯一高亮、关闭最终标签后空白、技能扫描和真实离线安装、磁盘文件编辑后关闭保存。
- 安装后的技能使用内置 Node 生成图并渲染；App 关闭后可自动启动；`--scale 1/2` 实测输出 1460×255 / 2920×510；非法图返回错误，缺令牌和浏览器 Origin 请求返回 401，令牌文件权限 0600。
- 视觉验收修复生成模板连线穿字、子节点重叠、长标签占用固定列宽等问题；打开图稿自动居中并缩放以显示内容。
- 测试前备份 App 和 SQLite；清理临时测试图后逐条核对原有 16 条记录，名称、图形、状态、附件、删除标记均保持一致。
